# 水果銷售出貨系統 — 系統概覽

## 1. 目的
提供水果現場銷售與出貨作業的數位化系統，取代目前紙本/口頭通知方式。核心價值：

- 銷售組送單後**即時**通知出貨組
- 出貨組即時看到待出貨訂單，依狀態流程備貨
- 庫存同步更新
- 完整保存客戶與訂單紀錄
- 後台統計每日營業資訊

**不需要** ERP、會計、薪資等複雜功能。

## 2. 角色與裝置

| 角色 | 主要裝置 | 主要功能 | 可見金額 |
|------|---------|---------|---------|
| 銷售組 (sales) | 手機 | 建立訂單、查商品/庫存 | ✅ |
| 出貨組 (shipper) | 手機 | 接單、更新出貨狀態 | ❌ |
| 管理者 (admin) | 電腦 | 統計、商品管理、全部資料 | ✅ |

預計同時在線 3～10 人。

## 3. 部署型態
- **PWA**（手機網頁 App），支援 Android / iPhone / 電腦瀏覽器
- 不上架 App Store / Google Play
- 可安裝到桌面（Add to Home Screen），支援推播通知

## 4. 系統架構

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│ 銷售組 PWA   │   │ 出貨組 PWA   │   │ 管理後台 Web │
│  (手機)      │   │  (手機)      │   │  (電腦)      │
└──────┬──────┘   └──────┬──────┘   └──────┬──────┘
       │                 │                 │
       └────────┬────────┴────────┬────────┘
                │ HTTPS REST API   │ WebSocket / SSE (即時推送)
                ▼                  ▼
          ┌──────────────────────────────┐
          │        後端 API Server        │
          │  Auth / Orders / Products /   │
          │  Inventory / Stats / Realtime │
          └──────────────┬───────────────┘
                         ▼
                  ┌──────────────┐
                  │  資料庫 (DB)  │
                  └──────────────┘
```

## 5. 核心資料實體
- **User** 使用者（含角色）
- **Customer** 客戶
- **Product** 商品（含圖片、庫存、上架狀態）
- **Order** 訂單（含明細 OrderItem）
- **ShipmentStatusLog** 出貨狀態變更紀錄

詳見 `02-backend-spec.md` 的資料模型章節。

## 6. 訂單狀態流程
```
待出貨 (pending) → 備貨中 (preparing) → 已出貨 (shipped)
```
- 訂單建立時狀態為 `pending`
- 每次狀態變更記錄時間與操作者
- 進入 `shipped` 時自動記錄 `shipped_at`
